摩斯电码工具

文本与摩斯电码双向转换，支持声音播放和速度调节

支持英文字母、数字和常用标点，不区分大小写

使用说明

  • 在文本框输入英文/数字/标点，自动生成摩斯电码
  • 在摩斯电码框输入电码，自动解码为文本（双向实时转换）
  • 摩斯电码中字符间用空格或 / 分隔，单词间用 /（前后带空格）分隔
  • 播放声音：用蜂鸣音播放电码，可调节速度（WPM）和音调（Hz）
  • WPM（Words Per Minute）为国际标准速度单位，按 PARIS 标准计算
  • 不支持的字符（如中文）在编码时会被忽略
